# California Housing Regression

## Objective
The objective of this project is to compare different regression
algorithms for predicting median house values using the California
Housing dataset.

## Algorithms Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Support Vector Regressor

## Evaluation Metrics
- Mean Squared Error
- Mean Absolute Error
- R² Score

## Techniques Used
- Data preprocessing
- Exploratory Data Analysis
- Feature scaling
- Train-test split
- 5-fold cross-validation
- Hyperparameter tuning using GridSearchCV

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
